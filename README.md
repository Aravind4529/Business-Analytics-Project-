# Business Analysis & Project Management Report – CourseFinder.ai Enhancement

## Overview

This repository contains the detailed business analysis and project management documentation for the CourseFinder.ai web application enhancement project, conducted for Skill Pointers, an education consulting firm. The project focused on improving the platform’s scalability, user experience, and backend performance to better support international students seeking Australian university admissions.

**Repository Structure:**

Business-Analytics-Project/

/- Business Analysis Project.pdf - Contains full Business Analysis report

/- README.md - Documentation

# Key Deliverables

- Comprehensive Business Analysis including stakeholder identification, requirements gathering, and market research

- Detailed Stakeholder Management Plan with roles, engagement strategies, and communication protocols

- Structured Project Communication Plan leveraging formal and informal channels for effective collaboration

- Project Planning artifacts featuring Work Breakdown Structure (WBS), Gantt charts, and Earned Value Management (EVM) for cost and schedule control

- Risk Management Framework identifying, assessing, and mitigating project risks across development phases

- Ethical Considerations addressing data privacy, fairness, and compliance with international standards (ISO 27001, GDPR)

- Final project conclusions with an overview of accomplishments, lessons learned, and recommendations for future enhancements

# Technologies & Frameworks Used

- Business Process Modeling (BPMN)

- Agile and Waterfall Methodologies

- Microsoft Project and Jira for task scheduling and issue tracking

- Data analytics tools for performance metrics

- Cloud computing principles for scalability planning

# Project Impact

- Streamlined user engagement and personalized course recommendation strategies

- Enhanced backend architecture for improved scalability and responsiveness

- Managed stakeholder expectations and communication effectively to minimize project risks

- Ensured ethical handling of sensitive user data and adherence to privacy laws
